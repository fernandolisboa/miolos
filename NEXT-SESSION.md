## Start here

**Termo free play** (#333, ADR-0114): `free-play/termo-free-screen.tsx` plays through `useFreeTermoBoard` (`free-play/use-free-termo.ts`), which judges on the device and shares `termo/use-termo-board.ts` with the daily. Its _Variante_ menu (#374, ADR-0135) adds Dueto and Quarteto: `free-play/termo-variants.tsx` and everything it reaches (`useTermoVariant`, `SplitKeyboard`, `judgeBoards`) load through `lazyChunk` after mount; the draft (`editDraft` in `termo/state.ts`) is shared with the daily, and the layout hooks (`--boards-across`, `--tile-gap`, `--notice-min`, `--keyboard-gap`, `--grid-card-pad`, `--title-display`) default to the daily's values. The pool is `@miolos/games/termo-free`; the answer list is `@miolos/games/termo-answers`, banned in `apps/web` source.

**Campo Minado** (#373, ADR-0133, ADR-0136): `free-play/minesweeper-free-screen.tsx` plays the engine through `minesweeper/use-minesweeper.ts` (a reducer, a clock, the mine counter) and `minesweeper/minefield.tsx`. The engine state carries `size`, and the free screen keeps `level` and `seed` in `MinesweeperPlay`. Until #389 PR 2 it is a free-play-only game: `FreePlayGame` in `free-play/catalog.ts` is `Game | "minesweeper"`, `GAMES` is unchanged. The chrome has no hint, no undo and *Novo jogo* in the reset slot. Pointer rules are `play/use-cell-press.ts` (middle, both buttons, a 350 ms long press); cells stay 24px and the well scrolls (`--board-floor-side`), and below 1280px of viewport Especialista turns 16×30 when its well is under 30 cells (from 1280px it stays landscape, overhanging its column). jsdom has no layout: re-measure in a browser.

**Hints** (ADR-0099, ADR-0101): each game's `next<Game>Hint` (`apps/web/src/<game>/hint.ts`) sits on `nextLogicalHint` (`play/grid-hint.ts`); the reason and spotlight live in `HintState<R>`. The reason shows in a card on the hinted cell (#332, ADR-0113): the chrome lazy-loads `HintCard` (`play/hint-card.tsx`); the visually hidden live region is the screen-reader copy, so tests read it through `SPOKEN` (`test/hint-reason.ts`). The loader ignores a chunk that lands after unmount (T-WEB-S720); that race was the `window is not defined` CI flake.

**Player settings** (#300, ADR-0102): one device-local key, `miolos-settings`, read through `useSettings` (`settings/settings.ts`). A new setting is a schema field, a copy entry and a key in `settings.games[game]`. Per-game options: ADR-0104 (struck clues), ADR-0105 (Rainhas), #322, #323, #325, #329. Account sync is #317.

The engine is `@miolos/games/colored-nonogram` (pools 34/46/19; tone pairs a colour-blind player confuses are dropped), walled to `src/colored-nonogram/**` and `use-free-colored-nonogram.ts`. Both brushes share `nonogram/paint.ts`. Cores does not strike resolved numbers yet. Every free-play picker is a `Choice` (`free-play/choice.ts`); a Variante is `variantChoice`, shared by Termo, Sudoku and the Nonogram.

**`/admin`** (ADR-0097, ADR-0100): admins are verified attached emails in `admin_users`. The free hint allowance is the `freeHintsPerPuzzle` key (ADR-0098); before rolling either app back, set it to 3 or less and wait for the rollover.

**Shared play chrome** (ADR-0077): `PlayScreenChrome` holds four stateful children, `UndoControl` (ADR-0126), `ResetControl` (ADR-0096), `GameSettingsButton` and `HintCard`. Undo, Recomeçar and Ajustes share one row; `.reset` is the positioned box the confirm spans (T-WEB-S810). **Undo** (#367, ADR-0126): each grid game's exported reducer is wrapped by `undoable` (`play/undo.ts`), which keeps an in-memory `history` of board snapshots, one per gesture; `useBoardEdits` gives the chrome `onUndo` and `onReset`. New board state must join that game's snapshot; state that does not derive from `entries` must also be listed in `undoable`'s step fields, as Sudoku's `notes` are (#368, ADR-0127: *Rascunho*, local masks, `sudoku/notes.ts`, `use-sudoku-input.ts` shared by the daily and free screens). The exception is the mistake count (#369, ADR-0128): `withMistakes` (`play/mistakes.ts`) wraps each grid reducer outside `undoable` through `usePlayReducer`, so undo never refunds it; each game's `state.ts` exports its rules (judge, cross, held presses), and a new grid game joins by exporting them.

**Boards size from the space they have** (ADR-0103): `BoardCard` wraps every board in a size container; `--board-below` mirrors the rows under the card by hand. jsdom has no layout, so re-measure in a browser (360×780 to 1440×900) after any change to the shared sheet.

Free play offers Clássico, Diagonal and Formas through the _Variante_ trigger and menu Termo also uses (`free-play/variant-trigger.tsx`, `variant-menu.tsx`). ## Traps

**Turbo's cache for `packages/db` tests does not cover `apps/api/src`.** Run `pnpm test --force` before trusting a green gate after an `apps/api` change. **Dependabot npm PRs cannot be merged as opened** (no lockfile change). Land one hand-made bump, outside `minimumReleaseAge` (7 days). **A perfect day needs a lineup buffered before midnight (ADR-0087).** The buffer alert exists to prevent that. **Six per-game medals is T-CORE-S70's maximum.** A seventh game needs that cap raised first.

**Content is not a Turbo test input.** After editing `content/crossword/lexicon.tsv`, `content/termo/answers.csv` or `content/termo/reserve.txt`, run `generate:crossword`, `generate:termo` and `pnpm test --force`. Re-curation moves a published answer to `reserve.txt`, never deletes it (ADR-0114).

**Never roll either app back past #330 part 3 once a 7×7 day exists** (ADR-0117): the old API answers a 49-cell completion 400 and sync drops it for good. Stop 7×7 with a forward PR that generates at 5. Before about 2026-10-22, check both production deployments are on the merge commit. Likewise a Rainhas record with `autoCrossed` fails the pre-#326 schema: sync pending completions before rolling `apps/web` back past #326. A pre-#368 client's `strictObject` rejects a Sudoku record that has `notes`, so an in-progress board with notes looks missing there and is overwritten on a rollback; solved records never carry notes. The same holds for `mistakes` (#369): a pre-#369 client rejects an open record that has it; closed records never carry it.
