# Miolos — Domain Glossary

The ubiquitous language. Issue titles, test names, proposals and specs use these terms exactly; don't drift to synonyms. Code and identifiers use the English term; the pt-BR term is what users see. Maintained by `/domain-modeling`; decisions behind the terms live in [`docs/adr/`](./docs/adr/).

| Term (code) | pt-BR (UI) | Meaning |
|---|---|---|
| **Daily** | Puzzle do dia | The one puzzle per game per day, identical for every user, published by the server. The unit of the ritual. |
| **Rollover** | Virada | Midnight `America/Sao_Paulo`, fixed for everyone. The only clock that matters; the client clock is never a source of truth. |
| **Published** | Publicado | Visible to clients: `published_at <= now()` through the single shared query helper ([ADR-0010](./docs/adr/0010-publication-is-time-driven-published-at-plus-buffer.md)). Unpublished rows exist server-side only ([ADR-0004](./docs/adr/0004-no-unpublished-puzzle-reaches-the-client.md)). |
| **Buffer** | — | The pre-generated, validated, future-dated `daily_puzzles` rows the cron keeps topped up. Monitoring watches its depth. |
| **Completion (on time)** | Conclusão | A daily solved during its own `America/Sao_Paulo` day — or synced exactly one day late by a user the server itself saw online on that day (the **seen day** credit). Decided once at write time and **stored** on the completion row; no read path re-derives it. The only event that feeds the streak ([ADR-0008](./docs/adr/0008-completion-and-streak-semantics-across-play-modes.md), [ADR-0066](./docs/adr/0066-a-late-sync-is-credited-from-a-server-seen-day.md)). |
| **Late completion** | Conclusão tardia | A past daily whose stored write-time verdict is late (`on_time = false`). Recorded; never feeds streak, time stats or Dia Perfeito, and never the Termo guess distribution's buckets 1–6 — a *lost* archived Termo is **played**, not completed, so it still lands in the fail row ([ADR-0008](./docs/adr/0008-completion-and-streak-semantics-across-play-modes.md) rule 3, [ADR-0053](./docs/adr/0053-the-archive-is-a-public-past-only-read-and-a-late-write.md) decision 8). **One carve-out**: yesterday's daily solved by a user the server saw online on that day is not late at all — it stores `on_time = true` and is a **Completion (on time)**, archive URL or not, because the server cannot distinguish an archive solve from a queued offline flush of the same date ([ADR-0066](./docs/adr/0066-a-late-sync-is-credited-from-a-server-seen-day.md)'s archive-credit consequence). Shown distinctly in the calendar when its date falls inside the account's own range — a date before the calendar's **range start**, which the rollover slack extends one day past the account's birth day, is off-calendar and paints no cell ([ADR-0053](./docs/adr/0053-the-archive-is-a-public-past-only-read-and-a-late-write.md)). It counts in `solved` totals and in the volume medals either way ([ADR-0051](./docs/adr/0051-statistics-are-read-time-derivations-on-closed-contracts.md), [ADR-0052](./docs/adr/0052-medals-are-derived-facts-plus-curated-grants.md)). |
| **Played** | Jogado | Reached a terminal state without winning. Only Termo can end here; a lost Termo feeds the guess distribution's fail row and nothing else. |
| **Win** | Vitória | Outcome `won` on a completion row. Medals and totals count won rows — a lost Termo is played, never won ([ADR-0008](./docs/adr/0008-completion-and-streak-semantics-across-play-modes.md) rule 3). *Vencer* is the completion vocabulary's verb for it. |
| **Streak** | Sequência | Consecutive days with ≥ 1 on-time completion. Always derivable from completion rows; any stored value is a cache ([ADR-0009](./docs/adr/0009-account-merge-recomputes-from-the-union-of-completions.md)). Computed server-side only. |
| **Dia Perfeito** | Dia Perfeito | All four dailies completed on time on one day. A lost Termo forfeits it ([ADR-0051](./docs/adr/0051-statistics-are-read-time-derivations-on-closed-contracts.md)). |
| **Stats calendar** | Calendário | The per-date history view: completed on time, completed late, or missed, from the account's first SP day (backward-extended by at most the **rollover slack**, and only by a won row); missed is the absence of a won row; a late completion dated before that extended start is **off-calendar** — it paints no cell and still feeds the aggregates; a Dia Perfeito is its rare marker ([ADR-0008](./docs/adr/0008-completion-and-streak-semantics-across-play-modes.md), [ADR-0051](./docs/adr/0051-statistics-are-read-time-derivations-on-closed-contracts.md), [ADR-0053](./docs/adr/0053-the-archive-is-a-public-past-only-read-and-a-late-write.md)). |
| **Archive** | Arquivo | The public, indexable collection of past dailies, starting at the first production-published date — the data is the record, no stored anchor. Routes: `/arquivo` (index), `/arquivo/mes/<mês>`, `/arquivo/<data>`, `/arquivo/<data>/<jogo>`; today's date redirects — the day URL to the hub, the play URL to that game's daily route ([ADR-0013](./docs/adr/0013-canonical-domain-and-pt-br-routes.md), [ADR-0053](./docs/adr/0053-the-archive-is-a-public-past-only-read-and-a-late-write.md)). |
| **Share text** | — | The string a conclusion produces for pasting into a chat: game, date, result, the per-day permalink, and — for Termo alone — the tile grid as coloured squares. Composed on the device from the local play record ([ADR-0031](./docs/adr/0031-per-device-day-state-is-a-local-monotone-safe-affordance.md) decision 6 — an affordance, never an entitlement) and therefore never carrying the answer, any guess word, a board or a picture, nor the streak, a medal, a solved total or a hint count, nor any claim about *when* the day was solved ([ADR-0054](./docs/adr/0054-the-share-is-plain-text-and-the-card-is-a-nameplate.md)). Three of the four games have no shape, and that is the product's asymmetry rather than a gap. **It is not spoiler-free by construction and this glossary does not say it is** — a Termo grid narrows the answer measurably (median 77 of 400 candidates under a consistent-play attacker, min 4; two grids median 19), which is deliberate solving against a product with no ranking rather than the spoiler broadcast [ADR-0004](./docs/adr/0004-no-unpublished-puzzle-reaches-the-client.md) `:11-13` scopes the threat to. |
| **Write window** | Janela de escrita | The route-layer rule for which day a completion or a guess may target: any day up to and including São Paulo today. **Upper bound only**; publication is the wall's question, not this one — the wall is the sole authority on which past days exist. Owner: `isWritableDate` (`apps/api/src/publishing/dates.ts`). Capped in volume, never in date, by the per-user-per-SP-day **late-write ceiling** ([ADR-0026](./docs/adr/0026-completions-are-write-once-rows-on-time-is-derived.md), [ADR-0053](./docs/adr/0053-the-archive-is-a-public-past-only-read-and-a-late-write.md)). |
| **Late-write ceiling** | — | At most 50 completions per user per São Paulo day whose stored write-time verdict is late (`not on_time`) — a rate rule on the writer, never a date rule on the puzzle. Enforced **inside** the insert, so a concurrent burst cannot count-then-write past it; refused with `429 archive-cap`, which is deliberately not terminal for the offline queue. A **credited** write (stored `on_time = true`) is exempt: it never takes the guarded arm and never spends the budget — a player at the ceiling still lands the credited flush ([ADR-0066](./docs/adr/0066-a-late-sync-is-credited-from-a-server-seen-day.md) decision 8). ADR-0026 decision 7's UNSEEN post-rollover flush is inside the ceiling by construction, at most 4 rows ([ADR-0053](./docs/adr/0053-the-archive-is-a-public-past-only-read-and-a-late-write.md) decision 13). |
| **Seen day** | — | A server-recorded fact that a user was online on a São Paulo date: one `user_seen_days (user_id, date)` row, written by the session service's three authentication hooks with the DB clock naming the day, never a client assertion. Consulted exactly once per completion, at write time, inside `POST /completions` — no streak, statistics, medal or day-state computation reads it, so a streak stays derivable from completion rows alone ([ADR-0009](./docs/adr/0009-account-merge-recomputes-from-the-union-of-completions.md)). It is what credits a one-day-late sync as on time; rows older than `today − 1` are pruned by the daily cron; merged by union ([ADR-0066](./docs/adr/0066-a-late-sync-is-credited-from-a-server-seen-day.md)). |
| **Rollover slack** | — | The one-day backward extension of the **stats calendar's** range, for a birth-midnight completion that legitimately predates the account's first SP day. Owner: `ROLLOVER_SLACK_DAYS`. **Not the write window**, never was, and never to be used as one again — a clamp that followed the write window would paint fabricated "missed" days ([ADR-0051](./docs/adr/0051-statistics-are-read-time-derivations-on-closed-contracts.md), [ADR-0053](./docs/adr/0053-the-archive-is-a-public-past-only-read-and-a-late-write.md)). |
| **Free play** | Modo livre | Infinite client-generated puzzles ([ADR-0011](./docs/adr/0011-free-play-is-generated-on-the-client.md)). Records nothing server-side. Termo excluded. |
| **Medal** | Medalha | One of 20–30 curated awards (23 at v1). Rule-derived medals recompute from completion rows on every read; curated grants are explicit rows; only earned medals ever render ([ADR-0052](./docs/adr/0052-medals-are-derived-facts-plus-curated-grants.md)). No XP, levels or ranking behind them ([ADR-0006](./docs/adr/0006-monetization-convenience-not-access.md)). |
| **Curated grant** | Medalha concedida | An explicit `medal_grants` row for a medal not computable from completion rows (founder/cheater class, [ADR-0006](./docs/adr/0006-monetization-convenience-not-access.md)). Unioned-and-deduped on merge, earliest grant date winning ([ADR-0009](./docs/adr/0009-account-merge-recomputes-from-the-union-of-completions.md), [ADR-0052](./docs/adr/0052-medals-are-derived-facts-plus-curated-grants.md)); rule-derived medals are never stored. |
| **Hint** | Dica | One free per puzzle **in the three grid games**; Termo ships none, because its board is output and there is nothing to hint ([ADR-0045](./docs/adr/0045-the-termo-screen-ships-no-hint-and-no-clock.md)). Extras arrive as day-scoped grants recorded server-side, expiring at rollover ([ADR-0006](./docs/adr/0006-monetization-convenience-not-access.md)). Never a balance. |
| **Attach** | Vincular e-mail | Adding an email to an anonymous account (prompted at streak ≥ 5). Recovery consent and reminder consent are separate ([ADR-0012](./docs/adr/0012-minimal-lgpd-ships-with-email-attach.md), [ADR-0050](./docs/adr/0050-email-attach-magic-link-tokens-consents-and-the-lgpd-minimum.md)). |
| **Onboarding** | — | The first-visit introduction: one dismissible in-flow paper card on the hub, after the game cards, selling the ritual (the four dailies, the sequência, the virada) — never the per-game rules, which live on the play screens. Shows until acknowledged; the acknowledgement is a server-side `users.onboarding_seen_at` timestamp — once per identity, surviving attach/merge, folded earliest-wins on merge ([ADR-0061](./docs/adr/0061-onboarding-seen-is-a-users-timestamp-merged-earliest-wins.md)). Never blocks reaching a puzzle ([ADR-0003](./docs/adr/0003-anonymous-first-identity-with-email-recovery.md)). |
| **Reminder** | Lembrete | The one push notification type: a streak-at-risk warning, opt-in via the conclusion-surface pre-prompt after the server-computed streak reaches the remote threshold (default 3), never marketing ([ADR-0064](./docs/adr/0064-streak-at-risk-is-a-derived-decision.md)). Consent is the browser permission plus a stored `push_subscriptions` row (whose `created_at` is the consent evidence); the prompt's decline or a browser denial stamps `users.push_prompt_dismissed_at` — permanent, once per account, surviving merge earliest-wins. *Lembrete* is also the word for the email hedge's reminder (its consent is separate — [ADR-0012](./docs/adr/0012-minimal-lgpd-ships-with-email-attach.md)). |
| **Magic link** | Link mágico | The single-use emailed link that proves an email and executes attach, recovery, device move or merge-on-collision — one flow, no password. Its token is stored hash-only, expires in 30 minutes, and is spent by one atomic claim; the link lands on `/vincular` and only an explicit POST consumes it ([ADR-0003](./docs/adr/0003-anonymous-first-identity-with-email-recovery.md), [ADR-0050](./docs/adr/0050-email-attach-magic-link-tokens-consents-and-the-lgpd-minimum.md)). |
| **Merge** | — | Two anonymous accounts joining under one email: union of completions, dedupe per puzzle keeping the earliest, everything derived recomputed ([ADR-0009](./docs/adr/0009-account-merge-recomputes-from-the-union-of-completions.md)). |
| **Tombstone** | — | The losing `users` row after a merge: its sessions are remapped to the canonical (winning) user and the row itself is emptied of every identity handle (`email`, `email_verified_at`, `apple_id`, `google_id`) and retained, never deleted — so its anonymous token can never resurrect a second identity, and its cookie must map to the merged identity, not to a revived empty account ([ADR-0009](./docs/adr/0009-account-merge-recomputes-from-the-union-of-completions.md), [ADR-0049](./docs/adr/0049-account-merge-one-pure-function-one-idempotent-operation.md)). |
| **Entitlement** | — | A string in `entitlements: string[]` (never a boolean). Dormant in v1. |
| **Normalized form** | — | A word after Unicode-decompose, strip combining marks, `ç`→`c`. Termo matching is accent-insensitive; tiles reveal the **canonical form** (correct accented spelling) on completion ([ADR-0015](./docs/adr/0015-termo-word-list-is-ai-curated-under-mechanical-constraints.md)). |
| **Guess** | Tentativa | One five-letter word a player submits. Six per daily (`MAX_GUESSES`). Judged server-side ([ADR-0038](./docs/adr/0038-termo-guesses-are-judged-by-a-stateless-server-route.md)); never judged on the client. |
| **Answer** | Palavra do dia | The day's word, drawn from the curated answer list. Stored on the row in both forms; never in a client payload before the board closes. |
| **Tile** | — | One of the thirty cells of the Termo board. Read-only output: a player writes guesses, not tiles ([ADR-0042](./docs/adr/0042-the-termo-board-is-read-only-output.md)). |
| **Tile state** | certa · na palavra · fora | `correct` / `present` / `absent` (`evaluate.ts:3`). The pt-BR words are one spelling per concept and are the words a screen reader speaks. |
| **Keyboard state** | — | The best-known state per letter across every judged guess, precedence `correct > present > absent` (`keyboard.ts:12-16`). A letter never guessed is *absent from the map*, not `absent`. |
| **Draft** | — | The letters typed into the active row and **not yet submitted**. Never persisted, never posted, and — because the tiles are `aria-hidden` — the only thing a screen reader can be told about while a word is being written. *Rascunho* is deliberately **not** the UI word: no visible string names it, and the aria copy says *escrevendo*. |
| **Held turn** | aguardando | A guess that has been submitted and whose verdict has not arrived. **Not consumed** — the turn survives a failure — and never persisted. It is a tile state, a row aria word and the one condition under which the retry button appears ([ADR-0039](./docs/adr/0039-termo-cannot-be-played-offline.md)). |
| **Answer list** | — | The 400 curated answers a daily may draw from (`TERMO_ANSWERS`). Finite content: no answer is ever drawn twice ([ADR-0040](./docs/adr/0040-the-termo-daily-stores-the-drawn-answer.md)), and Termo is excluded from free play because of it. |
| **Validation dictionary** | Lista de palavras aceitas | The words a guess may be (`TERMO_VALIDATION_WORDS`; sized by `VALIDATION_COUNT` — 5 408 as of #140). Membership is the base lexicon plus the curated, editorial `content/termo/additions.txt` ([ADR-0062](./docs/adr/0062-termo-guess-dictionary-gaps-close-with-curated-additions.md)). Also called the **guess dictionary** — ADR-0062's name for it when contrasting it with the answer list; same concept. Public by design — it ships to the client so "não está na lista" is instant and offline. A superset of the answer list in normalized form. |
| **Guess distribution** | — | How many guesses each won Termo took, plus the fail row ([ADR-0051](./docs/adr/0051-statistics-are-read-time-derivations-on-closed-contracts.md)). |
| **Fail row** | — | The lost-Termo bucket of the guess distribution. A lost Termo feeds this and nothing else ([ADR-0008](./docs/adr/0008-completion-and-streak-semantics-across-play-modes.md) rule 3). |
| **Motif** | — | An entry in the Nonogram picture library inside `packages/games`. Never user-facing: its name and id reach no client payload and are rendered nowhere; since ADR-0046/ADR-0047 the library rides the free-play chunk (generation needs the tables), while daily-route and shared chunks stay motif-free. |
| **Reveal** | — | The withheld part of a Nonogram daily: which motif it is, how it is oriented, and the picture bitmap the server judges completions against — `{motifId, name, mirrored, solution}`. Stripped from every published projection; the client is served clues only and recovers the bitmap itself from them ([ADR-0033](./docs/adr/0033-the-nonogram-reveal-ships-no-name.md)). |
| **Picture** | Figura | What a solved Nonogram grid paints. The client-rendered payoff, shown on the conclusion screen. |
| **Filled** | Preenchida | A Nonogram cell the player painted: `filled`, encoded `1` on the wire. The filled set is what a completion is judged on. |
| **Crossed** | Marcada | A Nonogram cell the player ruled out: `crossed`, encoded `0`. Notation for the player, never a claim about the picture. |
| **Undecided** | Vazia | A Nonogram cell the player has not decided: encoded `null` client-side, with no named constant. Avoid "empty" for it — `EMPTY_LINE` in `nonogram/board.tsx` is the all-empty CLUE line's sentinel, a different concept. |
| **Clues** | Números | The run lengths on a Nonogram's row and column rails: `clues`, whose entries are `runs`. Never *dicas* or *pistas* — a **dica** is the one free hint. |

**Games** (v1, build order): **Binairo**, **Sudoku**, **Nonogram**, **Termo** — "Termo" is the product's name for its Termo-like game; don't call it Wordle.

**Terms to avoid:** "win streak" (streaks count completions, not wins — except that a lost Termo alone doesn't complete); "coins/points/XP" (vetoed concepts, [ADR-0006](./docs/adr/0006-monetization-convenience-not-access.md)); "premium content" (nothing is gated, [ADR-0005](./docs/adr/0005-all-content-is-free.md)); "Picross", "Griddler", "Hanjie", "paint-by-numbers" (the game is **Nonogram**); *dica* or *pista* for a Nonogram's clue rails (those are **números**; *dica* is the hint).
